# Introduction to ToDo-APP

ToDo-APP is a web application designed to manage tasks. It offers a simple and user-friendly interface to:
- Create and manage tasks.
- Mark tasks as completed.
- Delete unnecessary tasks.

## Objective
To facilitate personal or group organization through an efficient and customizable digital tool.

---

## Target Audience
- Individual users who need a personal organizer.
- Small teams looking to manage tasks collaboratively.
