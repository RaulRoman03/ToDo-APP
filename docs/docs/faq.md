# Frequently Asked Questions (FAQ)

### 1. How to create an account on ToDo-APP?
To create an account, follow these steps:
1. Click on the **"Sign Up"** button on the home page.
2. Enter your details such as username, email, and password.
3. Confirm your email (if required) and you can start using the app.

### 2. How to add tasks to the list?
To add a new task:
1. Click on **"Add Task"** on the user interface.
2. Fill in the required fields such as the task title and description.
3. Click on **"Save"** to add the task to your list.

### 3. How can I delete a task?
To delete a task:
1. Locate the task you want to delete in the list.
2. Click the **trash can** icon next to the task.
3. Confirm the deletion if necessary, and the task will be removed from the list.

### 4. How can I update a task?
To update a task:
1. Click the task you want to edit.
2. Edit the necessary fields, such as the title, description, or due date.
3. Click **"Save Changes"** to update the task.

### 5. Can I change the language of the app?
Currently, the app is only available in Spanish. However, support for more languages ​​is planned to be added in future updates. Stay tuned for app updates for more information on new available languages.
