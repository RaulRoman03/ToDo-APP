# End-to-End (E2E) Testing

End-to-end testing verifies that the entire application works correctly, from the front-end to the back-end, ensuring that the different components interact appropriately.

## Requirements

Before running E2E tests, make sure you have your development environment set up and your application running. This includes:

- Python installed on your machine.
- Development environment set up and your application running on the server.
- Testing tools set up, such as Selenium or Playwright (depending on your project setup).
